# AC Library Services — Backend

Java 21 + Spring Boot + Spring Data JPA + MySQL.

## GitHub
Create a separate GitHub repository:
`https://github.com/YOUR_GITHUB_USERNAME/ac-library-services-backend`

## Local
Set environment variables from `.env.example`, then:
```
mvn spring-boot:run
```

## Render
Deploy this folder as a Render Web Service. Build with Maven and start the generated JAR. Add Aiven DB variables in Render Environment settings.
